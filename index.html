pixelpusher

Framework-agnostic <pixel-pusher> web component for image selection with optional aspect-ratio cropping.

Install

npm install pixelpusher
import 'pixelpusher'
// or all-in-one:
import 'pixelpusher/bundle'

Default UI + crop

Built-in upload control; crop modal uses 16:9 and export caps. Events appear in the panel.
